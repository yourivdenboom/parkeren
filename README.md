# Parkeren

Persoonlijke hulp-app voor bezoekersparkeren via 2Park: bezoek aanmelden met één tik,
herinneringen voordat de tijd afloopt, verlengen en afmelden.

- De bestanden in de hoofdmap zijn het scherm (wordt gehost via GitHub Pages).
- `backend/park` is de Supabase Edge Function die met 2Park praat en de herinneringen verstuurt.
- `backend/test/sim.ts` test de logica tegen een nagebootste 2Park: `deno run backend/test/sim.ts`.

Er staan geen wachtwoorden of sleutels in deze repository. Onofficiële koppeling, niet verbonden aan 2Park.
